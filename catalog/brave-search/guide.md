## Try Brave Search

Configure a Brave API key on the host. This archived reference server makes requests using the host’s account quota.

Ask the agent to use `brave_web_search` for a public topic. Successful results contain matching pages. Both default search tools consume API quota; use a call budget if you want to cap tool requests.

The generated command above contains the catalog’s explicit default allowlist. Check the guest’s tool list before making calls and use the server’s argument schema for required fields. See [the CLI guide](/docs#connect) for guest configuration and [session controls](/docs#controls) for approvals, redaction, and expiry.
