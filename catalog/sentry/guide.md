## Try Sentry

Authenticate the host with a scoped Sentry token or the upstream device-code flow. Some search features may also need a model-provider key.

Ask the agent to use `find_organizations` and select an organization the host may access. Subsequent project and issue reads can reveal stack traces and private event data. The generic operation dispatcher remains excluded by default.
