## Try YouTube Transcripts

No credentials needed — the server fetches public YouTube transcripts. This is one of the original community MCP servers and still the most referenced transcript server.

Ask the agent to pull a video's `get_transcript` by URL or video ID, then summarize it, quote it, or translate key points. Transcripts are read-only public data; availability depends on whether the video has captions.

The generated command above contains the catalog’s explicit default allowlist. Check the guest’s tool list before making calls and use the server’s argument schema for required fields. See [the CLI guide](/docs/#connect) for guest configuration and [session controls](/docs/#controls) for approvals, redaction, and expiry.
