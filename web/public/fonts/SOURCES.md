# Landing page fonts

- Instrument Sans variable, weights 400–700, Latin WOFF2: https://fonts.google.com/specimen/Instrument+Sans
- IBM Plex Mono regular, Latin WOFF2: https://fonts.google.com/specimen/IBM+Plex+Mono

Font files downloaded from the Google Fonts CSS API. Both are distributed under the SIL Open Font License; licenses are included in this directory. Fonts are served locally with `font-display: swap`.
